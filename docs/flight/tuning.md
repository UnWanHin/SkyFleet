# 增益调参记录

> 所有数字都由 `python -m flightlab tune` 与 `flightlab/tuning.py` 实测得出，
> 不是估的。改增益前先重跑一遍，别引用过期数字。

## 1. 方法：先按带宽算，再扫描验证

凭手感试增益的问题是"没有起点也没有判据"。这里分两步：

**第一步——按带宽反推。** 位置环 PD 写成 `a = kd(kp·e − v)`，于是
`ωn = √(kp·kd)`、`ζ = kd/(2√(kp·kd))`。姿态环用几何 SE3，`k_R = I·ωn²`、
`k_ω = 2ζI·ωn`，其中 `I_yy ≈ 5.1e-5 kg·m²` 从模型读出来。

**第二步——扫描验证。** 一次只改一个参数，跑同一条 1 m 阶跃，比上升时间、
超调、调节时间、稳态误差、饱和占比。`sweep()` 强制遵守"只动一个"的纪律。

## 2. 阶跃方向必须是水平

第一次在 **z 轴**上扫 `k_R` 和 `k_omega`，三个取值扫出来**三行完全相同**。
一度以为扫描坏了，实际是物理如此：纯升降不需要倾斜机身，姿态环根本不参与。

**教训**：扫参前先问"这个参数在这条轨迹上有没有作用通道"。没有通道的扫描
结论是假的"没影响"，会让人错过真正的瓶颈。

## 4. 三个反直觉结论

### 4.1 加大姿态阻尼反而更快

`k_ω` 从 0.00138 提到 0.0028（ζ 从 0.9 到 1.8，超过临界阻尼）：

| | 上升 s | 超调 % | 调节 s | 航線最大角速度 |
|---|---|---|---|---|
| 0.00138 | 0.926 | 0.9 | 1.588 | 3.69 rad/s |
| **0.0028** | **0.820** | **0.0** | **1.482** | **2.62 rad/s** |

调节时间缩短 **7%**，最大角速度降低 **29%**。这不是"速度换平稳"，
是**更快 + 更平滑**的纯收益：阻尼够，姿态不用甩过头再甩回来。

按 ζ=0.9 反推只是个起点，实测告诉我还该更硬。这条已写成回归测试
（`test_more_attitude_damping_is_not_slower`）。

### 4.2 `v_max` 在 1.5 以上完全不起作用

1.5 和 2.5 三行数字一模一样。原因：`v_ref = kp·e = 1.562×1.0 = 1.562 m/s`，
本来就低于 2.5；真正的约束是 `a_max_horizontal = 3.0`，它先把加速度截住了。

**结论**：以为在调"速度上限"，实际在调"加速度上限"。参数的作用通道和名字
不一致时，光看名字会调错对象。

### 4.3 `a_max_horizontal` 提到 6.0 是更快的，但不该无条件用

调节时间 1.588 → 1.490 s，但水平加速度 6 m/s² 意味着 **31° 倾角**（当前
3.0 对应 17°）。完整航线上最大角速度从 3.69 涨到 5.55 rad/s（+50%），
实物上就是更大的电机应力。

**没有采纳**：报告演示不需要那 6% 的调节时间，换来 50% 的姿态激进度不值得。
如果将来要在强扰动下快速机动，再单独评估。

## 5. 当前默认值

```python
Gains(
    kp_pos=1.562, kd_pos=4.0,      # 位置环 ωn=2.5, ζ=0.8
    v_max=1.5, a_max_horizontal=3.0,
    k_R=0.0115, k_omega=0.0028,     # 姿态环 ωn=15, ζ≈1.8
    kp_motor=5.0e-5,                # 转速环（带前馈，只需修正）

```

完整五航点：最大跟踪误差 **1.16 mm**，轨迹长度 **9.64 m**，最大角速度
**2.62 rad/s**，末转速收敛到 **1873 rad/s**（悬停理论值 1872.7）。

## 6. 不能靠调参解决的两个结构性问题

调参过程中遇到两次"怎么调都调不出来"，都是结构问题不是数值问题。记下来
免得下次又在增益上浪费时间：

1. **姿态参考不可实现**。位置环一步要求 52° 倾角，姿态环指令力矩
   116 mN·m 而物理上限只有 12 mN·m，饱和后飞行器翻到 162°、飞出 238 m。
   解法是限幅水平加速度 + 按带宽重定增益，不是继续调 `k_R`。
2. **执行器比姿态环慢一个量级**。转速环只靠高增益消稳态误差，几十 rad/s
   的误差就打满力矩，退化成 bang-bang，与姿态环组成极限环，振幅涨到
   172 rad/s。解法是给转速环加**前馈** `k_m·ω²`，让比例项只管修正。

判据：如果调参时指标对参数完全不敏感、或者怎么调都振荡，先怀疑结构。
